# USDT Power Plan - Telegram Mining Simulator Bot & Mini App ⚡💎

একটি সম্পূর্ণ টেলিগ্রাম মাইনিং সিমুলেটর মিনি অ্যাপ এবং নোড.জেএস (Node.js) টেলিগ্রাম বট। এই অ্যাপটিতে বাস্তব কোনো হার্ডওয়্যার মাইনিং হবে না—এটি একটি আকর্ষণীয় এবং ডায়নামিক সিমুলেটেড মাইনিং কাউন্টার যা স্বয়ংক্রিয়ভাবে লাইভ ০.০০১২২ রেটে বৃদ্ধি পায়।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **রিয়েল-টাইম সিমুলেটেড মাইনিং কাউন্টার (Live Mining Counter):**
   - স্ক্রিনের শীর্ষে স্বয়ংক্রিয় লাইভ কাউন্টার যা প্রতি মুহূর্তে `0.00122...` USDT হারে জীবন্তভাবে বাড়তে থাকে।
   - স্পিড স্ট্যাটাস, লাইভ গ্রিন পালস ডট এবং প্রতি ঘন্টায় আয়ের হিসেব।
   - **Claim to Wallet** বোতাম: জমানো মাইনিং রিওয়ার্ড কনফেটি অ্যানিমেশন সহ মূল ওয়ালেটে জমা হয়।

2. **ডিপোজিট ও উইথড্র বোতাম (Deposit & Withdraw Buttons):**
   - মাইনিং কার্ডের নিচেই দুটি সুন্দর ও আধুনিক অ্যাকশন বাটন:
     - 📥 **ডিপোজিট (Deposit):** TRC20 এবং BEP20 নেটওয়ার্কের কিউআর কোড (QR Code), কপি বোতাম এবং সাথে সাথে পরীক্ষা করার জন্য **টেস্ট ডিপোজিট (+10 USDT)** অপশন।
     - 📤 **উইথড্র (Withdraw):** ঠিকানা ইনপুট, অ্যামাউন্ট, MAX বোতাম, গ্যাস ফি ক্যালকুলেশন এবং ইনস্ট্যান্ট সাবমিট।

3. **সাদা ও ক্লিন ব্যাকগ্রাউন্ড (Minimal Clean White Theme):**
   - অতিরিক্ত গোল সার্কেল বাদ দিয়ে আধুনিক ফিনটেক কার্ড ডিজাইন (Modern Fintech Card UI)।
   - ঝকঝকে টাইপোগ্রাফি (`Plus Jakarta Sans` ও ক্রিপ্টো সংখ্যার জন্য `JetBrains Mono`)।
   - হালকা ছায়া ও সফট ট্রানজিশন।

4. **নিচের নেভিগেশন বার (Bottom Navigation Bar):**
   - ⛏️ **মাইনিং (Mining):** হোম স্ক্রিন ও লাইভ কাউন্টার
   - ⚡ **পাওয়ার প্ল্যান (Plans):** স্টার্টার ফ্রি (0.00122 USDT/h), ব্রোঞ্জ, সিলভার, গোল্ড ও ডায়মন্ড টার্বো আপগ্রেড প্ল্যান
   - 💼 **ওয়ালেট (Wallet):** মোট ব্যালেন্স, অদাবিকৃত মাইনিং ব্যালেন্স এবং সাম্প্রতিক লেনদেনের হিস্ট্রি
   - 👥 **রেফারেল (Friends):** রেফারেল লিংক কপি এবং টেলিগ্রামে ১-ক্লিকে শেয়ার
   - 👤 **প্রোফাইল (Profile):** ইউজার আইডি, টেলিগ্রাম হ্যান্ডেল, বাংলা/ইংরেজি ভাষা পরিবর্তন ও সাপোর্ট

5. **টেলিগ্রাম বট ও নোড.জেএস ব্যাকএন্ড (Node.js & Express API):**
   - Express 5 সার্ভার যা এপিআই এবং রিয়্যাক্ট ক্লায়েন্ট একসাথে রান করে।
   - টেলিগ্রাম বট হ্যান্ডলার (`server/bot.js`): `/start`, `/mine`, `/help` এবং ইনলাইন **Web App** বোতাম।

## 🚀 রান করার নিয়ম (How to Run)

### ১. ডিপেন্ডেন্সি ইনস্টলেশন
ইতিমধ্যে সমস্ত প্যাকেজ ইনস্টল করা আছে। প্রয়োজনে রান করুন:
```bash
npm install
npm --prefix client install
```

### ২. প্রোডাকশন বিল্ড এবং সার্ভার চালু করা
```bash
# ক্লায়েন্ট বিল্ড করুন
npm run build:client

# ফুল-স্ট্যাক সার্ভার চালু করুন (Port 3000)
npm start
```
ব্রাউজারে গিয়ে দেখুন: [http://localhost:3000](http://localhost:3000)

### ৩. ডেভেলপমেন্ট মোড (HMR সহ)
```bash
npm --prefix client run dev
```

## 🤖 টেলিগ্রামের সাথে যুক্ত করার নিয়ম (Telegram Bot Setup)

১. টেলিগ্রামে [@BotFather](https://t.me/BotFather) এ যান।
২. `/newbot` লিখে একটি নতুন বট তৈরি করুন এবং **Bot Token** সংগ্রহ করুন।
৩. প্রজেক্টের `.env` ফাইলটি খুলুন এবং আপনার টোকেন বসান:
   ```env
   PORT=3000
   WEBAPP_URL=https://your-domain-or-ngrok.app
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```
৪. লোকাল টেস্ট করার জন্য [ngrok](https://ngrok.com) বা Cloudflare Tunnel ব্যবহার করতে পারেন:
   ```bash
   ngrok http 3000
   ```
   এবং পাওয়া HTTPS লিংকটি `WEBAPP_URL`-এ বসান।
৫. `@BotFather` এ `/setmenubutton` কমান্ড দিয়ে আপনার বট সিলেক্ট করে ওই HTTPS লিংকটি WebApp হিসেবে সেট করুন।
৬. আপনার টেলিগ্রাম বটে গিয়ে `/start` চাপলেই সরাসরি মিনি অ্যাপটি চালু হয়ে যাবে!
